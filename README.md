# Анализ многолетних среднесуточных расходов рек


## Идея

Проект посвящён анализу многолетней динамики суточных расходов воды (м³/с) на гидрологических постах (демонстрация на посте NORT-SUR-ERDRE на реке Эрдр). Данные взяты из глобального архива речных характеристик Global Runoff Data Centre (GRDC) (демонстрационный файл: data/6123170_Q_Day.Cmd.txt).

## Задачи

- Парсинг сырых данных GRDC — извлечь шапку метаданных и определить начало блока данных, разделить столбцы, записать в DataFrame и перезаписать данные в csv-таблицу.

- Дать сводку по всему ряду — период, число записей, число пропусков.

- Отсечь данные вне периода 2000–2020, так как это наиболее рабочий диапазон анализа (мало пропусков).

- Построить гидрограф (график хода расхода реки) за 2000–2020.

- Рассчитать средние по месяцам. Найти минимальные и максимальные среднемесячные расходы.

- Рассчитать среднегодовые расходы.

- Получить трендовое изменение расхода с 2000 по 2020 годы.

- Оценить линейный тренд за период. Уравнение Q = k·year + b.
